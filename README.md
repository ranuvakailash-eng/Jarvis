# JARVIS Mobile — Minimal HUD

This version intentionally keeps the interface extremely clean:
- black background
- cyan holographic dotted spiral
- subtle rotating HUD rings
- J.A.R.V.I.S. status
- listening animation
- tap-to-speak voice input

The design is inspired by the visual language of futuristic JARVIS/HUD interfaces while remaining an original implementation.

## Build
Open the project in Android Studio and run `assembleDebug`.

APK:
app/build/outputs/apk/debug/app-debug.apk

## Phone-only build
The project can also be uploaded to GitHub and built using the included GitHub Actions workflow if you do not have a PC.
